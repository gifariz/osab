# B11 3D tripod truss
Three bars from pinned supports (0,0,0), (4,0,0), (0,3,0) to an apex at (1,1,3), load (10, -5, -20) kN.
Statically determinate: bar forces from apex equilibrium, apex displacement by virtual work. Tests 3D truss
elements and automatic restraint of rotations.

Reference files: `hand.json` (15 values), `opensees.json` (39 values).

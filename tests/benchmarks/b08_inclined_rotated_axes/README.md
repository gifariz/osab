# B08 Inclined member with rotated local axes (3D)
Cantilever from (0,0,0) to (2,3,6), L = 7 m, local axes rotated 30 degrees. Tip load (3, -4, -10) kN plus 2
kN/m gravity along the member. Hand values: loads resolved into local axes, cantilever formulas per plane,
transformed back to global.

Reference files: `hand.json` (17 values), `opensees.json` (30 values).

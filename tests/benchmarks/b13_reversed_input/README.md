# B13 Members given against the usual end order (3D)
A column drawn top to bottom and two cantilever beams drawn towards the column (-X and -Y), with angles, local
and partial member loads. OSAB reverses them to the usual order and converts angle and loads. OpenSees runs
the file as written (so displacements and reactions check the conversion).

Reference files: `opensees.json` (30 values).

# B16 Column with a rigid L-shaped bracket (3D)
A fixed 3 m column carries an L-shaped bracket made of two rigid links: 1 m along +X, then 0.8 m along +Y.
Loads: (4, 0, -20) kN at the bracket tip, 3 kN in Y and a 1.5 kN m torque at the corner. Hand: the bracket
loads moved to the column top, cantilever formulas, the bracket moving rigidly with the column top, and link
forces from the loads beyond each cut.

Reference files: `hand.json` (60 values), `opensees.json` (42 values).

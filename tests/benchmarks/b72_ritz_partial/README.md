# B72 - Ritz vectors: four point masses on springs, 5 vectors from UX, UY, UZ

Four joints (2, 3, 5 and 7 t in X, Y and Z) on springs with periods 1.5 to 6.3 s apart in each direction,
rotations held; mass source joint masses only. A Ritz modal case with starting loads the accelerations UX, UY
and UZ, in that order, 5 vectors. The second cycle stops after UX and UY, so the order of the starting loads
shows in the modes.

Checks: periods and the UX, UY, UZ and RZ mass ratios (the masses lie at one height, so RX and RY have none).

Reference files: none published; `osab bench` runs the model to check that it solves.

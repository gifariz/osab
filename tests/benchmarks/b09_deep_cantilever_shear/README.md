# B09 Deep cantilever with shear deformation (2D)
Concrete 300 x 600 mm, L = 1 m, P = 100 kN. Shear area As = 5/6 A. Shear adds about 26% to the tip deflection
here, so this checks the shear-deformable frame stiffness (included by default).

Reference files: `hand.json` (6 values), `opensees.json` (15 values).

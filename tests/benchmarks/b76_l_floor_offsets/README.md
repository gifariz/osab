# B76 - L-shaped floor with automatic end offsets (the example model)

B42 as a model drawn in the app today: the same floor, beams, columns and loads, with the sections' depth and
width (columns 0.4 x 0.4 m, beams 0.5 m deep and 0.3 m wide, rectangles in the app) and automatic end offsets
(rigid-zone factor 0) on every frame, the default of a drawn frame. The beams' offsets are half the column
width (0.2 m), the columns' top offsets the beam depth (0.5 m). This is the app's L-shaped floor example (File
> Open Example and the web demo's first model).

Hand: reaction totals (the offsets change no total).

Reference files: `hand.json` (2 values).

# B10 3D one-bay space frame
Four 3.5 m columns (two rotated 90 degrees), beams 6 m in X and 5 m in Y, all listed in the usual end order
(lower Z, then X, then Y is end i). GRAV: 10 kN/m on all beams. LAT: lateral and vertical nodal loads, a point
load in local 3 and a partial uniform load in local 2. References from OpenSees.

Reference files: `opensees.json` (336 values).

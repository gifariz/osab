# B23 - U-shaped core wall

Three Shell-Thin walls (t = 0.25 m, 6 m high): a 4 m web along X at y = 0 and two 2 m flanges along Y at x = 0
and x = 4, meeting at shared corner joints; 1 x 1 m areas, base joints fixed.

- LAT: 10 kN in X at each of the five top web joints (50 kN).
- TORQ: +20 kN (Y) at the top of the x = 4 flange tip and -20 kN at the x = 0 flange tip (a torque).

Hand: base reaction totals.

# B06 Pratt truss (2D)
Four 3 m panels, 3 m deep, pin at node 1, roller at node 5, 20 kN down at nodes 2, 3 and 4. Statically
determinate: bar forces by the method of joints, midspan deflection by virtual work (sum N n L / EA). Tests
truss elements and automatic restraint of rotations at truss-only nodes.

Reference files: `hand.json` (15 values), `opensees.json` (53 values).

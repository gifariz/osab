# B12 Rotated column with local member loads and shear deformation (3D)
Vertical cantilever, 4 m, local axes rotated 30 degrees, shear areas As2/As3 given. Loads: uniform in local 2,
point in local 3, uniform axial (local 1), a global-X point load on the member, torque at the top. Hand
values: Timoshenko cantilever formulas in each local plane, transformed to global.

Reference files: `hand.json` (13 values), `opensees.json` (30 values).

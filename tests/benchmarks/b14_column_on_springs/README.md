# B14 Column on six base springs (3D)
A 3.5 m steel column whose base is held only by springs in all six DOFs (no restraint), with tip loads in X, Y
and Z, a moment about X and a torque. The springs carry the whole load, so their forces (reported as
reactions) follow from statics; base movement = force / k, and the tip moves with the base plus the cantilever
deformation.

Reference files: `hand.json` (30 values), `opensees.json` (30 values).

# B66: steel section list

A 6 m cantilever column of steel list sections (AISC Shapes Database v16.0: W, C, WT, L, 2L, rectangular and
round HSS, pipe, HP), fixed at the base, model in kN and m: tip forces of 10 kN along X (FX) and Y (FY), and
self weight (DEAD). Each section is given by its AISC name (`{"type": "aisc"}`) from the AISC 16 list.

- Hand: statics.

Reference files: `hand.json` (40 values).
